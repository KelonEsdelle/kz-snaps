# KZ.Snaps Website

A responsive photography and editing portfolio starter site.

## Files
- `index.html` — page content and sections
- `style.css` — responsive dark/minimal styling
- `script.js` — mobile menu, image lightbox, current year, WhatsApp links
- `images/` — put your own locally stored images here if you want to replace remote demo photos

## Before publishing
1. Open `script.js`.
2. Replace `1868XXXXXXXX` with your WhatsApp number in international format, digits only. For Trinidad & Tobago, use `1868` followed by your number. Do not include `+`, spaces, or dashes.
3. Replace the demo Unsplash image URLs in `index.html` and the hero/contact backgrounds in `style.css` with your own images. Search for `images.unsplash.com` to find each location.
4. Update the About text and service descriptions to match what you actually offer.
5. Test every WhatsApp link on your phone.

## Publish free with GitHub Pages
1. Create or sign in to a GitHub account at https://github.com.
2. Create a new public repository, for example `kz-snaps`.
3. Upload `index.html`, `style.css`, `script.js`, and your `images` folder to the repository root.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then save.
7. Wait for GitHub Pages to publish; the URL will be shown on the Pages settings screen and usually looks like `https://yourusername.github.io/kz-snaps/`.

## Other hosting
Netlify and Vercel can also host a static site. You can deploy by connecting the GitHub repository.

## Notes
- The site uses Google Fonts and demo images hosted by Unsplash, so those require an internet connection.
- The website is static: there is no booking database or payment processing included.
- Use only photos you own or have permission to display.
